# DDT แรงยิง

แอป Android ช่วยคำนวณแรงยิงเกม DDT แบบ Bubble ลอยทับเกม (โหมดมืดสไตล์ iOS)

**ดาวน์โหลด:** [ddt-aim.apk ล่าสุด](https://github.com/ONISAN1999/ddt-aim/releases/latest/download/ddt-aim.apk)

## ใช้งาน
1. เปิดแอป กดปุ่มเป้าเล็งมุมขวาบนเพื่อเปิด Bubble (อนุญาต "แสดงทับแอปอื่น" ครั้งแรก)
2. สลับไปเกม แตะลูกบอลเพื่อเปิดตัวคำนวณ · ลากเพื่อย้าย · กดค้างเพื่อปิด
3. **กดเลข:** ใส่ระยะเป็นช่อง (1 จอ = 10 ช่อง) ใส่ความต่างระดับถ้ามี แล้วเลือกลม
4. **เลือกจากแผนที่:** กดแคปจอ ขยายแผนที่ย่อ แล้วแตะ ขอบซ้าย-ขวาของกรอบจอสีขาว → ตัวเรา → เป้า
   (กรอบจอจำไว้ ครั้งต่อไปแตะแค่ตัวเรากับเป้า)

## สูตร
จำลองทีละก้าว 0.04 วินาที ตามสคริปต์เกม (กระสุนมาตรฐาน: ax = R(24·ลม − 0.2·vx), ay = R(700 − 0.2·vy))
แล้วลองแรง 0–100% หาแรงที่ผ่านใกล้เป้าที่สุด (ห่างไม่เกิน 20 px = โดน)

## ออกเวอร์ชันใหม่
1. แก้ `versionCode` (+1) และ `versionName` ใน `app/AndroidManifest.xml` และเขียน `app/notes.txt`
2. Build ด้วย `./build.sh` แล้ววางไฟล์ที่ `dist/ddt-aim.apk` (หรือตั้ง secrets `KS_B64`/`KS_PASS` ให้ CI build เอง)
3. Push ขึ้น `main` → Actions สร้าง Release + `version.json` → แอปในเครื่องเห็นแถบอัปเดตเอง
